# MU-Nodes

木易维护的 ComfyUI 自定义节点集合，按文本、加载、媒体处理和工具职责组织。

## 节点分类

- `MU/文本`：多字符串合并、文本查看与格式化。
- `MU/加载`：多图片加载、多视频加载和媒体链接加载。
- `MU/媒体处理`：视频压缩、视频与图片序列转换、视频截取、音频截取、智能视频切片、获取视频信息。
- `MU/工具`：提示词拆分与组装、链接列表拆分、视频规划与片段整理、尺寸选择、宽高比判断、时长与帧数计算。

`MU｜智能视频切片`支持最长时长和最短镜头规则。最长时长大于 0 时作为单段硬上限，在时间窗内选择符合最短镜头要求的自然切点；没有合格切点时在上限处切分。最长时长为 0 时不强制切分，最短镜头为 0 时不筛除自然切点。节点可接入视频或图片序列；图片序列可额外连接音频。输入来源必须且只能选择一种。输出切片结果可由 `MU｜获取视频切片` 按序号提取为视频、图片序列和音频。

## 安装

将整个目录放入 ComfyUI：

```text
ComfyUI/custom_nodes/MU-Nodes/
```

在 ComfyUI 使用的 Python 环境安装依赖，并重启 ComfyUI：

```powershell
python -m pip install -r requirements.txt
```

重启后，在节点库搜索 `MU`。
